Este componente documenta todas las variantes y configuraciones disponibles para los componentes de header en el framework Kite: kite-header, kite-layout-header, kite-header-options y kite-header-notif-profile.

1. Header type="internal"

Es el tipo más utilizado en la aplicación. Muestra una barra de navegación interna con título, flecha de retroceso (backAction) y opcionalmente menú hamburguesa (hasOptions).

1a. Básico — solo título

Código:
<kite-header
  type="internal"
  title="Título de la página"
  [hasOptions]="false"
></kite-header>
Resultado:

1b. Con backAction (flecha atrás)

Código:
<kite-header
  type="internal"
  title="Préstamos prendarios"
  [hasOptions]="false"
  (backAction)="onBackAction('internal')"
></kite-header>
Resultado:

1c. Con menú hamburguesa (hasOptions=true)

Código:
<kite-header
  type="internal"
  title="Mi Cuenta"
  [hasOptions]="true"
  (backAction)="onBackAction('internal-options')"
  (menuAction)="onMenuAction('internal-options')"
></kite-header>
Resultado:

1d. Con extraIcon

Código:
<kite-header
  type="internal"
  title="Descargar documento"
  [hasOptions]="false"
  extraIcon="download"
  (backAction)="onBackAction('internal-extra')"
  (extraIconAction)="onExtraIconAction('internal-extra')"
></kite-header>
Resultado:

1e. Con CSS personalizado

Código:
<kite-header
  type="internal"
  title="Header personalizado"
  [hasOptions]="false"
  [css]="{ backgroundColor: '#1a1a2e', color: 'white' }"
  (backAction)="onBackAction('internal-css')"
></kite-header>
Resultado:

1f. Con link

Código:
<kite-header
  type="internal"
  title="Documentación"
  [hasOptions]="false"
  link="https://kite.supervielle.com"
  (backAction)="onBackAction('internal-link')"
></kite-header>
Resultado:

2. Header type="section"

Header para secciones principales de la aplicación. Muestra un estilo diferente al internal, pensado para páginas de nivel superior.

2a. Básico

Código:
<kite-header
  type="section"
  title="Inicio"
  [hasOptions]="false"
></kite-header>
Resultado:

2b. Con menú hamburguesa

Código:
<kite-header
  type="section"
  title="Productos"
  [hasOptions]="true"
  (menuAction)="onMenuAction('section')"
></kite-header>
Resultado:

2c. Con backAction y extraIcon

Código:
<kite-header
  type="section"
  title="Inversiones"
  [hasOptions]="false"
  extraIcon="settings"
  (backAction)="onBackAction('section-extra')"
  (extraIconAction)="onExtraIconAction('section-extra')"
></kite-header>
Resultado:

3. Header type="taskFocused"

Header diseñado para flujos de tarea enfocados (wizards, formularios multi-paso). Muestra un botón de cierre (closeAction) en lugar del menú, ideal para modales de pantalla completa o procesos paso a paso.

3a. Básico — con closeAction

Código:
<kite-header
  type="taskFocused"
  title="Solicitar préstamo"
  (closeAction)="onCloseAction('taskFocused')"
></kite-header>
Resultado:

3b. Con backAction y closeAction

Código:
<kite-header
  type="taskFocused"
  title="Paso 2 de 4 — Datos personales"
  (backAction)="onBackAction('taskFocused-back')"
  (closeAction)="onCloseAction('taskFocused-back')"
></kite-header>
Resultado:

3c. Con extraIcon

Código:
<kite-header
  type="taskFocused"
  title="Confirmar operación"
  extraIcon="info"
  (closeAction)="onCloseAction('taskFocused-extra')"
  (extraIconAction)="onExtraIconAction('taskFocused-extra')"
></kite-header>
Resultado:

4. Header type="public"

Header para páginas públicas (landing, marketing, pre-login). Soporta iconos especiales (phoneAction, locationAction, searchAction) y dos botones visibles (mainButton rojo y extraButton blanco).

4a. Básico

Código:
<kite-header
  type="public"
  title="Banco Supervielle"
  [hasOptions]="false"
></kite-header>
Resultado:

4b. Con mainButton y extraButton

Código:
<kite-header
  type="public"
  title="Banco Supervielle"
  mainButton="Abrir cuenta"
  extraButton="Iniciar sesión"
  (mainButtonAction)="onMainButtonAction('public')"
  (extraButtonAction)="onExtraButtonAction('public')"
></kite-header>
Resultado:

4c. Con iconos de contacto (phone, location, search)

Código:
<kite-header
  type="public"
  title="Sucursales"
  (phoneAction)="onPhoneAction('public')"
  (locationAction)="onLocationAction('public')"
  (searchAction)="onSearchAction('public')"
></kite-header>
Resultado:

4d. Completo — todos los features

Código:
<kite-header
  type="public"
  title="Banco Supervielle"
  [hasOptions]="true"
  mainButton="Abrir cuenta"
  extraButton="Iniciar sesión"
  (menuAction)="onMenuAction('public-full')"
  (phoneAction)="onPhoneAction('public-full')"
  (locationAction)="onLocationAction('public-full')"
  (searchAction)="onSearchAction('public-full')"
  (mainButtonAction)="onMainButtonAction('public-full')"
  (extraButtonAction)="onExtraButtonAction('public-full')"
></kite-header>
Resultado:

5. Dentro de kite-layout-header

kite-layout-header es un componente estructural del kite-layout. Funciona como un slot de proyección de contenido: envuelve un kite-header para posicionarlo correctamente dentro del layout. Solo acepta un input [css].

5a. kite-layout-header standalone (sin kite-layout)

Código:
<kite-layout-header>
  <kite-header
    type="internal"
    title="Header en layout-header (standalone)"
    [hasOptions]="false"
    (backAction)="onBackAction('layout-standalone')"
  ></kite-header>
</kite-layout-header>
Resultado:

5b. kite-layout-header con CSS personalizado

Código:
<kite-layout-header [css]="{ borderBottom: '3px solid #ee2527' }">
  <kite-header
    type="internal"
    title="Header con borde rojo"
    [hasOptions]="false"
    (backAction)="onBackAction('layout-css')"
  ></kite-header>
</kite-layout-header>
Resultado:

6. Layout completo con Header + Secondary

Ejemplo del patrón más completo: kite-layout con kite-layout-header, kite-layout-main y kite-layout-secondary. Este es el patrón canónico usado en la aplicación (ej: prestamo-page-layout).

6a. kite-layout + kite-layout-header + kite-layout-main

Código:
<kite-layout>
  <kite-layout-header>
    <kite-header
      type="internal"
      title="Página con layout"
      [hasOptions]="false"
      (backAction)="onBackAction('layout-full')"
    ></kite-header>
  </kite-layout-header>
  <kite-layout-main
    [css]="{ backgroundColor: '$gray_transparent_lighter', padding: '$md' }"
  >
    <p>Contenido principal del layout.</p>
  </kite-layout-main>
</kite-layout>
Resultado:

Contenido principal del layout.

6b. kite-layout con secondary="left"

Código:
<kite-layout secondary="left">
  <kite-layout-header>
    <kite-header
      type="internal"
      title="Dashboard"
      [hasOptions]="false"
      (backAction)="onBackAction('layout-secondary')"
    ></kite-header>
  </kite-layout-header>
  <kite-layout-secondary [css]="{ backgroundColor: '$gray_transparent_lighter', padding: '$md' }">
    <p>Sidebar izquierdo</p>
  </kite-layout-secondary>
  <kite-layout-main [css]="{ padding: '$md' }">
    <p>Contenido principal</p>
  </kite-layout-main>
</kite-layout>
Resultado:

Sidebar izquierdo

Contenido principal

7. kite-header-options

Componente complementario para renderizar un menú desplegable de opciones. Se usa junto a un kite-header con hasOptions=true. Acepta un array de opciones (máx. 5) con title y action.

7a. Con título de opciones

Código:
<kite-header-options
  [options]="headerOptions"
  optionsTitle="Menú principal"
  [hasOptionsTitle]="true"
></kite-header-options>
Resultado:

7b. Sin título de opciones

Código:
<kite-header-options
  [options]="headerOptions"
  [hasOptionsTitle]="false"
></kite-header-options>
Resultado:

8. kite-header-notif-profile

Componente para mostrar avatar del usuario, notificaciones y accesos rápidos a perfil, configuración y seguridad. Ideal para dashboards y áreas autenticadas.

8a. Con username (muestra iniciales)

Código:
<kite-header-notif-profile
  [username]="'Juan Pérez'"
  [hasNotifications]="true"
  [notificationsList]="notificationsList"
  (moreNotificationsAction)="onMoreNotifications()"
  (perfilAction)="onPerfilAction()"
  (settingsAction)="onSettingsAction()"
  (securityAction)="onSecurityAction()"
></kite-header-notif-profile>
Resultado:

8b. Sin notificaciones

Código:
<kite-header-notif-profile
  [username]="'María García'"
  [hasNotifications]="false"
  (perfilAction)="onPerfilAction()"
  (settingsAction)="onSettingsAction()"
  (securityAction)="onSecurityAction()"
></kite-header-notif-profile>
Resultado:

9. Combinaciones avanzadas

Ejemplos de combinaciones más complejas entre los componentes de header y layout.

9a. Layout con header type="section" + menú + main

Código:
<kite-layout>
  <kite-layout-header>
    <kite-header
      type="section"
      title="Panel principal"
      [hasOptions]="true"
      (menuAction)="onMenuAction('combo-section')"
    ></kite-header>
  </kite-layout-header>
  <kite-layout-main [css]="{ padding: '$md' }">
    <p>Contenido de la sección.</p>
  </kite-layout-main>
</kite-layout>
Resultado:

Contenido de la sección.

9b. Layout con header type="taskFocused"

Código:
<kite-layout>
  <kite-layout-header>
    <kite-header
      type="taskFocused"
      title="Paso 1 — Verificar identidad"
      (backAction)="onBackAction('combo-task')"
      (closeAction)="onCloseAction('combo-task')"
    ></kite-header>
  </kite-layout-header>
  <kite-layout-main [css]="{ padding: '$lg' }">
    <p>Formulario de verificación aquí.</p>
  </kite-layout-main>
</kite-layout>
Resultado:

Formulario de verificación aquí.

9c. Layout con header type="public" completo

Código:
<kite-layout>
  <kite-layout-header>
    <kite-header
      type="public"
      title="Banco Supervielle"
      mainButton="Hazte cliente"
      extraButton="Login"
      (mainButtonAction)="onMainButtonAction('combo-public')"
      (extraButtonAction)="onExtraButtonAction('combo-public')"
      (phoneAction)="onPhoneAction('combo-public')"
      (searchAction)="onSearchAction('combo-public')"
    ></kite-header>
  </kite-layout-header>
  <kite-layout-main [css]="{ padding: '$lg' }">
    <p>Landing page content.</p>
  </kite-layout-main>
</kite-layout>
Resultado:

Landing page content.

10. Referencia completa de API

kite-header

Propiedad / Evento Tipo Descripción
Inputs
type 'section' | 'internal' | 'taskFocused' | 'public' Requerido. Variante visual del header.
title string | undefined Texto del título.
hasOptions boolean Muestra/oculta el ícono de menú hamburguesa.
extraIcon any Nombre del ícono adicional (ej: "help-circle", "info", "settings").
mainButton string | null Texto del botón rojo (solo type="public").
extraButton string | null Texto del botón blanco (solo type="public").
link string URL de enlace.
css any Overrides de estilos (Stitches-style tokens).
Outputs (Eventos)
(backAction) EventEmitter Click en la flecha de retroceso.
(menuAction) EventEmitter Click en el ícono hamburguesa.
(closeAction) EventEmitter Click en el ícono de cerrar (type="taskFocused").
(extraIconAction) EventEmitter Click en el extraIcon.
(phoneAction) EventEmitter Click en el ícono de teléfono (type="public").
(locationAction) EventEmitter Click en el ícono de ubicación (type="public").
(searchAction) EventEmitter Click en el ícono de búsqueda (type="public").
(mainButtonAction) EventEmitter Click en el mainButton (type="public").
(extraButtonAction) EventEmitter Click en el extraButton (type="public").

kite-layout-header

Propiedad Tipo Descripción
css any Overrides de estilos. Wrapper de proyección para kite-header.

kite-header-options

Propiedad Tipo Descripción
options Array<{ title: string, action: Function }> Array de opciones (máx. 5). Cada item tiene title y action.
optionsTitle string | null Título de la sección de opciones.
hasOptionsTitle boolean Mostrar/ocultar el título de opciones.
css any Overrides de estilos.

kite-header-notif-profile

Propiedad / Evento Tipo Descripción
Inputs
username string | null Nombre del usuario. Muestra las iniciales en un avatar.
userImage string | null URL de la imagen del usuario para el avatar.
hasNotifications boolean Muestra/oculta el badge de notificaciones (punto rojo).
notificationsList Array<{ title, description, action }> Lista de notificaciones con acciones.
css any Overrides de estilos.
Outputs (Eventos)
(moreNotificationsAction) EventEmitter Click en "Ver más notificaciones".
(perfilAction) EventEmitter Click en "Perfil".
(settingsAction) EventEmitter Click en "Configuración".
(securityAction) EventEmitter Click en "Seguridad".

kite-layout (componente padre)

Propiedad Tipo Descripción
secondary 'left' | 'right' Posición del panel secundario.
bg string Color de fondo del layout.
css any Overrides de estilos.
Slots de contenido (orden de proyección): kite-layout-sidebar → kite-layout-header → kite-layout-main → kite-layout-secondary
